# petbottle_rocket

高校の物理部で取り組んだ、ペットボトルロケットの姿勢制御プロジェクトのリポジトリです。

## 概要
飛行中のロケットの姿勢を計測・制御することを目的に、6軸,9軸センサー（加速度・ジャイロ・方位磁針）
を用いた制御を試行しました。
使用したマイコン:Arduino Nano
使用したセンサ:MPU6500, bno055

## 担当した部分
姿勢制御用のプログラムはほぼ全て自分(kyoupie)が担当

## 試行錯誤した点
飛行中、加速度や角速度から数値積分をして高度と姿勢を算出するプログラムを書いた。
ジャイロセンサのドリフト効果によって誤差が蓄積する問題が発生したが、様々なフィルタや高性能な9軸センサを用いることによりほぼ解決することができた。

## 成果
チームとして全国高等学校総合文化祭（鹿児島）で発表しました。
